# التسويق الرقمي من الصفر

أكاديمية تفاعلية بالعربي (عامية مصرية) لتعلم أساسيات التسويق الرقمي من الصفر، جزء من منصة أكاديميات Infinity University Activity.

**الموقع المباشر:** https://capwv.github.io/digital-marketing-from-zero/

## المحتوى

- **14 درس** (13 درس + مشروع ختامي)
- **42 سؤال تفاعلي** بتصحيح فوري وشرح
- **28 تمرين** بحل نموذجي
- **معمل تسويق** جوه المتصفح: حاسبة أرقام الإعلانات، حاسبة الربحية، تحديات حسابية بتتصحح تلقائياً، وسيناريوهات قرارات
- كل أرقام الأمثلة والحلول محسوبة بالكود وقت البناء

## الدروس

1. إيه هو التسويق الرقمي؟
2. الجمهور والـ Persona
3. العرض والـ Value Proposition
4. الـ Funnel ورحلة العميل
5. المحتوى والـ Copywriting
6. الـ SEO
7. السوشيال ميديا
8. الإعلانات والأرقام
9. إعلانات السوشيال
10. الإيميل والواتساب
11. الصفحة والتحويل
12. التحليل والقياس
13. الحسابات والربحية
14. المشروع الختامي

## التقنية

صفحة واحدة بدون build: HTML + CSS + JavaScript خام. التسجيل والتقدم والشهادة من نفس نظام باقي الأكاديميات (cert.js).
